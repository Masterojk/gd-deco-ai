# Deco AI

Describe a vibe and **Claude** decorates your level, right inside the editor.

Press the green **AI** button next to undo in the editor.

## Decorate
- Type a vibe (e.g. *"bloody red horror, sharp thorns, embers"*), optionally the song BPM, and press **Decorate!**
- Or pick a preset (Bloodbath, Neon, Frost, Toxic, Void, Sunset). Presets work without an API key.
- Deco AI recolours the level, overlays your blocks with shaded fill, outlines and glow, adds a moving background, particles, beat pulses, colour changes and small motifs.
- Your gameplay blocks are never changed: deco is placed on top and can't be touched.
- Select part of the level and tick **Selection only** to decorate just that part.
- **Undo** removes the last run. Every run also gets its own group ID.

## Layout
Builds a rough layout (cube, ship, ball, UFO and wave parts) after the end of your level. Playtest and tweak it.

## Ideas
Ask Claude for level or mod ideas.

## API key
Claude features need your own Anthropic API key (console.anthropic.com), set in the mod settings. Each run costs a small amount.
